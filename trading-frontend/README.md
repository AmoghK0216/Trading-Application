# Trading Frontend

## Step 1: Basic Setup ✅

A minimal React + TypeScript + Tailwind CSS application.

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

The app will run at `http://localhost:3000`

## What's Included

- ✅ React 18 + TypeScript
- ✅ Vite (fast build tool)
- ✅ Tailwind CSS with custom theme
- ✅ Grayish-black primary colors
- ✅ Sky blue accent colors
